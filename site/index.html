크롬 Ink2로 쓰는
가장 가벼운 PDF 필기 노트

Chromium 순정 PDF 뷰어(PDFium)와 Ink2 필기 엔진을 그대로 사용합니다. 별도 렌더러도, 직접 만든 필기 엔진도 없습니다. 펜으로 쓰면 지정한 폴더에 알아서 저장돼요.

쓰는 데만 집중하도록

굿노트처럼 가볍게, 크롬 PDF 엔진처럼 정확하게.

✍️

초미니멀 한 줄 툴바

펜 · 형광펜 · 지우개 · 실행 취소 · 저장만. 위쪽 한 줄이 기본이고, 원하면 오른쪽 한 줄로 내릴 수 있어요.

🖐️

팜 리젝션

스타일러스(pen)만 필기, 손가락(touch)은 스크롤과 핀치 줌만 동작합니다.

📈

단계형 유사 필압

필압 0/20/40/60/80% 구간으로 1~5단계 굵기. 고른 최대 단계가 상한이에요.

🎨

펜 프리셋 슬롯

펜과 형광펜을 여러 개 만들고, 슬롯마다 색(크롬 기본 / 커스텀)과 굵기를 저장합니다.

🖥️

듀얼 스크린 발표

화면공유용 창은 순수 PDF만 보여주고, 페이지·줌·스크롤을 실시간 미러링. 외부 모니터를 감지하면 전체화면으로 열려요. 레이저 포인터는 양방향으로 동기화됩니다.

📁

지정 폴더 자동 저장

저장 대화상자 없이 폴더에 덮어쓰기. 주기적 자동 저장과 안전한 임시 파일 교체로 데이터를 지킵니다.

📄

규격 입력으로 빈 노트

A4·Letter·16:9 또는 mm 직접 입력. 빈 종이·줄·모눈·점선, 페이지 추가, PNG/선택 쪽 내보내기까지.

📊

PPT 가져오기

Microsoft Office가 설치된 PC에서는 PPT를 PDF로 변환해 바로 노트로 만듭니다.

이렇게 동작해요

크로미움을 통째로 빌드하지 않습니다.

CEF 표준 바이너리 위에서 Chrome 런타임으로 실행, 내장 PDF 뷰어와 Ink2를 그대로 사용합니다.
resources.pak 자동 패치 — PDF 뷰어 번들만 언팩해 툴바·입력 처리를 수정하고 재패키징합니다. CEF 버전을 올려도 스크립트 한 번이면 끝.
로컬 루프백 서버가 노트 목록, 빈 PDF 생성, 페이지 추가, 원자적 저장을 담당합니다.

다운로드

Windows 10/11 x64 포터블 ZIP. 압축을 풀고 CrPDF.exe를 실행하세요.
